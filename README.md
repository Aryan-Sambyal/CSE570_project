# Predictive Maintenance Using Machine Learning

## Project Overview
This project aims to develop a Machine Learning-based Predictive Maintenance system that identifies potential machine failures using industrial operational and sensor data.

Predictive maintenance helps industries reduce unexpected equipment failures, minimize downtime, and improve operational efficiency by identifying possible failures before they occur.

## Objectives
- Understand and analyze industrial machine sensor data.
- Perform Exploratory Data Analysis (EDA).
- Clean and preprocess the dataset.
- Implement and compare multiple Machine Learning classification algorithms.
- Evaluate models using appropriate performance metrics.
- Identify important features contributing to machine failures.
- Apply model explainability techniques.

## Dataset

**Dataset:** AI4I 2020 Predictive Maintenance Dataset

**Source:** [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset)

The dataset contains approximately 10,000 observations and includes machine operating conditions such as:

- Air Temperature
- Process Temperature
- Rotational Speed
- Torque
- Tool Wear
- Machine Type

**Target Variable:** Machine Failure

The dataset ZIP file is included in this repository.
